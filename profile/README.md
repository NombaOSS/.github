# Nomba open source

Official, open-source tools for building on the [Nomba](https://nomba.com) payments API: accept payments, send transfers, pay bills and receive webhooks.

| Project | What it is | Install |
|---|---|---|
| [Nomba Node.js SDK](https://github.com/NombaOSS/nomba-node) | TypeScript and Node.js SDK | `npm install @nombaoss/nomba-node` |
| [Nomba Python SDK](https://github.com/NombaOSS/nomba-python) | Python SDK, sync and async | `pip install nomba` |
| [Nomba PHP SDK](https://github.com/NombaOSS/nomba-php) | PHP 8.1+ SDK | `composer require nombaoss/nomba-php` |
| [Nomba MCP Server](https://github.com/NombaOSS/nomba-mcp) | The Nomba API as tools for AI apps | `npx -y @nombaoss/nomba-mcp` |
| [Nomba Agent Skills](https://github.com/NombaOSS/skills) | Teaches AI coding agents to integrate Nomba safely | `npx skills add NombaOSS/skills` |
| [Nomba OpenAPI Spec](https://github.com/NombaOSS/openapi) | OpenAPI definition of the Nomba API | [openapi.json](https://github.com/NombaOSS/openapi/releases/latest/download/openapi.json) |

**Docs:** [developer.nomba.com](https://developer.nomba.com) · **Security:** report vulnerabilities to security@nomba.com, never in a public issue.
